# Changelog

## 0.1.0 — Public preview

- Single-owner Google Calendar workspace with validated operations and approval boundaries.
- Independent reminders, deterministic routines and optional AI daily/weekly briefings.
- Revisioned personal memory, reusable programs, shopping lists and indexed archive retrieval.
- English interface, owner communication profile, full-page assistant and light/dark/device themes.
- Optional Telegram, isolated AGY, offline transcription, speech playback and SearXNG research.
- Local Docker preview, interactive persistent setup, safe diagnostics and deployment documentation.

This is the first clean-history public snapshot. Private installation history and personal runtime data are not part of the source release. See README.md for operating limits and integration prerequisites.
